# NextX creative studio redesign

## Direction

Keep the actual NextX logo and identity: warm paper, ink, orange, Archivo and IBM Plex Mono. Large editorial type, asymmetric project imagery, generous spacing and clear Dutch copy. Real work carries the page. The globe is a supporting studio detail about working from Paramaribo.

Three directions were considered:

- Editorial creative studio: selected because it accommodates photography, brand systems, digital work and marketing without making the business look like a template shop.
- Technical production interface: too narrow for a multidisciplinary creative agency.
- Sparse experimental portfolio: would conceal useful existing content and enquiry routes.

Reference research: [COLLINS](https://wearecollins.com/) for type and project hierarchy; [Awwwards agency websites](https://www.awwwards.com/websites/agency/) for varied studio structures; [Awwwards photography websites](https://www.awwwards.com/websites/photography/) for image-first presentation. These informed principles, not copied layouts or artwork.

## Information and behavior

Four disciplines lead services: Web & Software, Fotografie & Media, Branding & Design and Marketing. Existing website packages and genuine demo links remain below those disciplines in expandable categories. Copy describes a core team coordinating appropriate specialists. No blanket delivery promise, invented photography portfolio or claim that every specialist is in-house.

Homepage sequence: positioning, real selected work, disciplines, studio model, process, enquiry. Cases are data-driven with explicit draft/published state, accurate studio/client origin and presentation-specific media. Photography can use React Photo Album; Yet Another React Lightbox is imported on demand. Existing Motion and COBE remain; no additional animation framework was introduced. Content remains readable without animation and respects reduced motion.

## Visual review and checks

First review examined desktop and mobile homepage and services screenshots. The second pass brought real work higher by tightening the hero, compacted the package catalogue, corrected a 320px gallery overflow, changed mobile footer contact layout, and removed the about page's link to itself. Final screenshots use the production build and immediate scroll resets so fixed navigation is captured correctly.

Browser coverage: homepage, portfolio, services, studio/about, contact and both genuine project pages at 320, 375, 390, 430, 768, 1024 and 1440px. Screenshots are reviewed at 390 and 1440px. Checks include images loading, horizontal overflow, browser errors, one main heading, WCAG A/AA automated scans, menu Escape/focus, lightbox keyboard/focus, reduced motion, internal routes and mocked contact success/error. Automated scans supplement visual and keyboard review; they do not establish complete accessibility certification.
